# Frontend

React 19 + TypeScript application built with Vite.

## Commands

```text
npm install
npm run dev
npm run lint
npm run typecheck
npm test
npm run test:e2e
npm run build
```

Copy `.env.example` to `.env.local` when a non-default API base URL is needed. Only variables prefixed with `VITE_` are exposed to browser code; never place secrets in frontend environment files.
